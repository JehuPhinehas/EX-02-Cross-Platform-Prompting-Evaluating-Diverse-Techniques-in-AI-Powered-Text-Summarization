## CLAUDE :

 1️⃣ Basic Prompt

A Basic Prompt is a simple, direct instruction with minimal detail. It relies on the model's default behavior and general knowledge.

Example:

Summarize the following text.

[Paste article/paragraph here]

Characteristics:

Quick to write
No guidance on tone, length, or audience
Output can be inconsistent or generic

2️⃣ Role Prompt

A Role Prompt assigns the LLM a specific persona or expertise, which shapes vocabulary, tone, and depth of the response.

Example:

You are an experienced research analyst who specializes in simplifying 
complex academic papers for undergraduate students.

Summarize the following text.

[Paste article/paragraph here]

Why it helps:

Produces domain-appropriate language
Sets an implicit quality/expertise bar
Useful when tone should match a professional (teacher, journalist, lawyer, doctor, etc.)

3️⃣ Context Prompt

A Context Prompt provides background information — the purpose of the summary, the target audience, or the source of the content — so the model tailors its response appropriately.

Example:

The following text is an excerpt from a research paper on climate change, 
intended to be summarized for high school students who have no prior 
background in environmental science.

Summarize the following text.

[Paste article/paragraph here]

Why it helps:

Aligns output with audience understanding level
Reduces irrelevant or overly technical content
Improves relevance to the intended use case

4️⃣ Constraint Prompt

A Constraint Prompt sets explicit limits or rules — such as word count, number of points, tone, or things to avoid.

Example:

Summarize the following text in no more than 100 words. 
Do not include statistics or direct quotations. 
Use simple, easy-to-understand language.

[Paste article/paragraph here]

Why it helps:

Ensures predictable, controlled output
Prevents overly long or off-topic responses
Useful for fitting content into fixed spaces (slides, captions, reports)

5️⃣ Output Format Prompt

An Output Format Prompt specifies exactly how the response should be structured — bullet points, table, JSON, headings, etc.

Example:

Summarize the following text and present the output in this format:

Title: <short title for the summary>
Key Points:
- Point 1
- Point 2
- Point 3
